# 一页清单 · 学习待办

互联网软件开发课程的氛围编程小项目。使用 Codex，通过“简短描述 → 浏览器预览 → 追加描述”完成，无预先规约。

## 运行

直接用浏览器打开 `dist/index.html`，无需安装依赖。

也可以在项目目录执行：

```sh
python -m http.server 5173 --directory dist
```

然后访问 http://localhost:5173 。不同访问地址的本地数据互相独立。

## 功能

- 添加任务（支持回车，最多 100 字，忽略纯空白）
- 勾选完成与恢复未完成
- 删除单个任务
- 全部、待完成、已完成筛选
- 完成进度与剩余数量
- 浏览器本地保存，刷新后恢复
- 手机宽度适配、键盘操作与无障碍标签

## 技术

原生 HTML、CSS、JavaScript，无后端、第三方依赖和密钥。仓库不包含用户任务数据。任务仅存于当前浏览器的 localStorage，清除浏览器数据会删除清单；浏览器禁止存储时会显示提示。

## 项目结构

```text
dist/index.html   页面结构
dist/style.css    样式与响应式布局
dist/app.js       任务操作与本地存储
```
